# SWING LAB Official Website

山形県酒田市の24時間インドアゴルフスタジオ「SWING LAB」のトップページです。
添付のスマートフォンモックアップを基準に、写真中心の構成で再構築しています。
HTML / CSS / JavaScriptのみで実装し、ビルドやパッケージのインストールは不要です。

## ローカルで起動

Node.js 20以上が必要です（Node.js 24で確認）。

```bash
cd /workspace/swinglab
npm run dev
```

ブラウザーで `http://localhost:3000/` を開いてください。終了は `Ctrl+C`。
別のポートは `PORT=3002 npm run dev` で指定できます。
ファイルの保存後、ブラウザーを再読み込みすると変更が反映されます。
`npm start` でも同じローカル確認用サーバーが起動します。

サーバーは `0.0.0.0:3000` で待ち受けます。起動ログのLocal URLはクラウドマシン内部のアドレスです。手元のブラウザーから閲覧するには、クラウドサービス側のポート転送が必要です。環境再起動後は開発サーバーも再起動してください。

開発サーバーでは `/`、`/index.html` に加えて `/swinglab/`、`/swinglab/index.html` からも同じページを表示できます。`/swinglab` は相対パスが正しく解決されるよう `/swinglab/` にリダイレクトします。プレビュー中の古いCSS・画像が残らないよう、開発サーバーのレスポンスには `Cache-Control: no-store` を設定しています。

`https://hicolor-giten.github.io/swinglab/` はGitHub Pagesの公開サイトです。作業環境の未コミット・未プッシュの変更は表示されません。ここで新デザインを確認するには、確認済みの変更をmainへプッシュしてPagesのデプロイを完了させる必要があります。

## GitHub Pagesで公開

1. [Pages設定](https://github.com/Hicolor-Giten/swinglab/settings/pages) を開きます。
2. **Build and deployment → Source** を **Deploy from a branch** に設定します。
3. **Branch** で **main**、フォルダーで **/ (root)** を選び、**Save** を押します。
4. **Actions** でPagesのデプロイ完了を確認します。反映に数分かかる場合があります。
5. 公開先は通常 `https://hicolor-giten.github.io/swinglab/` です。実際のURLはPages設定で確認してください。

GitHub PagesではNode.jsサーバーを起動せず、静的ファイルをそのまま配信します。
`.nojekyll` を含め、ルートの `index.html`、`styles.css`、`app.js` と `assets/` を配信します。
画像・CSS・JavaScriptは相対パスで指定しており、`/swinglab/` 配下でも動作します。

## 構成

- `index.html`：ヘッダー、ヒーロー、4つの特徴、施設紹介、設備ギャラリー、料金カード、ご利用の流れ、アクセス、フッター
- `styles.css`：スマートフォン優先のレスポンシブデザイン、グリーン／ゴールドの固定予約ボタン
- `app.js`：予約URL設定、メニュー、設備ギャラリー、予約準備中ダイアログ
- `assets/logo.svg`：添付ロゴを目視で再現した仮SVG。正式原本ではありません。
- `assets/logo-mark.svg`：同じ仮SVGをもとにしたfavicon
- `assets/studio-concept.png`：施設イメージの生成画像
- `assets/golf-concept.png`：ゴルフボールのイメージ生成画像
- `server.mjs`：Node.js標準機能によるローカル確認用サーバー

旧デザインの `assets/simulator.svg` と `assets/favicon.svg` は未使用です。

## ロゴ・写真の差し替え

添付画像は会話上では確認できましたが、画像原本を作業環境から取得できなかったため、ヘッダーのロゴは目視で再現した仮SVGです。正式ロゴと完全一致するものではありません。元画像と同じ843:596の縦横比を保ち、CSSで変形させず表示しています。

正式ロゴの元ファイルが利用可能になったら、`index.html` 内のヘッダー・フッターのロゴ画像を差し替え、画像の実寸に合わせて `width` / `height` も設定してください。faviconも正式素材に合わせて差し替えてください。

施設・ゴルフ写真は生成した仮素材で、実施設や実機の写真ではありません。画面内と代替テキストにその旨を明記しています。施設外観は架空の建物写真を使わず、「外観写真は準備中」としています。設備ギャラリーの2枚目は施設イメージの拡大表示です。

実際の写真を用意したら、`index.html` の画像・代替テキスト・イメージ表記と、`app.js` の `slides` 配列を更新してください。レンタル用品は未確定のため「クラブ・ボール完備」などの断定は掲載していません。

## 予約リンクの差し替え

`app.js` 冒頭の `RESERVATION_URLS` に正式なURLを設定します。

```js
const RESERVATION_URLS = Object.freeze({
  member: null, // 会員予約の正式URL
  visitor: null, // ビジター予約の正式URL
});
```

`null` の間は全予約ボタンに「準備中・予約不可」を表示し、案内ダイアログを開きます。実際の予約・情報送信は行いません。
URLを設定すると、料金カードと固定バーの両方が同じURLに切り替わり、ボタンの準備中表示が消えます。
予約受付の開始時は、料金・プラン条件・ご利用の流れ・メタ説明・ダイアログなどの準備中表記も正式な情報へ更新してください。

## 掲載情報

- 料金は未確定のため「準備中」とし、仮の金額は掲載していません。
- 完全個室3打席・駐車場ありは今回の依頼で指定された内容を反映しています。駐車場所や入退館方法などの詳細は準備中です。
- ご利用の流れは予定です。利用回数・時間・会員登録・レンタルなどの未確定条件は断定していません。
- Googleマップは外部接続が必要です。表示できない場合に備えて、住所と外部地図リンクを併記しています。埋め込み表示時はGoogleへ接続します。

## 動作確認

`npm test` で、HTMLから参照するCSS・JavaScript・画像のHTTP応答、Content-Type、ルートと `/swinglab/` の両経路、末尾スラッシュへのリダイレクト、存在しないファイルの404応答を確認できます。外部パッケージは不要です。

Chromiumでローカル配信 `/` とGitHub Pagesを想定した `/swinglab/` を確認しています。

- 画面幅320 / 375 / 390 / 430 / 768 / 900 / 1024 / 1440pxで横スクロールがないこと。
- 画像の読み込み、ロゴの縦横比、ページ内リンク、モバイルメニューの開閉。
- 料金カード・固定バーの4つの予約リンク、準備中ダイアログ、Escapeでの終了・フォーカス復帰。
- 設備ギャラリーの矢印・サムネイル・キーボード操作・最初と最後の循環。
- 下部予約ボタンの固定表示とJavaScript実行エラーがないこと。

Googleマップはこの検証環境の外部アクセス制限により実表示を確認できていません。UI検証では埋め込み先を隔離しています。実際の地図表示・所在地は公開前に確認してください。

公開サイトへの反映は、mainへのプッシュ後にGitHub Pagesのデプロイが完了してから確認してください。正式ロゴ原本・実施設写真への差し替え、正式な料金・予約URLの設定は引き続き必要です。
