# SWING LAB Official Website

山形県酒田市の24時間インドアゴルフスペース「SWING LAB」のトップページです。
HTML / CSS / JavaScriptで実装し、ビルドや外部パッケージのインストールは不要です。

## ローカルで起動

Node.js 20以上が必要です（Node.js 24で確認）。

```bash
cd /workspace/swinglab
npm run dev
```

ブラウザーで `http://localhost:3000` を開いてください。終了は `Ctrl+C`。
別のポートを使う場合は `PORT=3001 npm run dev` で起動します。
ファイルを保存後、ブラウザーを再読み込みすると変更を確認できます。

### クラウド環境での表示

サーバーは `0.0.0.0:3000` で待ち受けます。起動ログの `Local` はクラウドマシン内のアドレスです。手元のブラウザーから閲覧するには、利用するクラウドサービスが提供するポート3000の転送・Webプレビュー機能が必要です。このプロジェクト自体は外部公開URLを発行しません。

環境を再起動した場合は、上記の `npm run dev` を再実行してください。HTTP応答は `curl -I http://127.0.0.1:3000/` で確認できます。

`npm start` でも同じローカル確認用サーバーが起動します。本番環境では、静的ファイルをHTTPS対応のホスティングサービスなどに配信してください。

## ファイル構成

- `index.html`：トップページ、施設情報、FAQ、Googleマップ、予約案内ダイアログ
- `styles.css`：レスポンシブスタイル、スマートフォン下部固定ボタン
- `app.js`：モバイルメニュー、予約準備中の案内、フッター年表示
- `assets/`：オリジナルの施設イメージイラスト・ファビコン
- `server.mjs`：Node.js標準機能のみで動くローカル確認用サーバー
- `.nojekyll`：GitHub PagesでJekyllによる変換をせず静的ファイルを配信

## GitHub Pagesで仮公開

1. [リポジトリのPages設定](https://github.com/Hicolor-Giten/swinglab/settings/pages) を開きます。
2. **Build and deployment → Source** を **Deploy from a branch** に設定します。
3. **Branch** で **main**、フォルダーで **/ (root)** を選び、**Save** を押します。
4. リポジトリの **Actions** でPagesのデプロイ完了を確認します。反映には数分かかることがあります。
5. 公開先は通常 `https://hicolor-giten.github.io/swinglab/` です。最終的なURLはPages設定の表示を確認してください。

公開後の更新はmainへのプッシュで反映されます。GitHub PagesではNode.jsサーバーや `npm run dev` は実行されません。ルートの `index.html` とCSS・JavaScript・画像をそのまま配信します。

CSS・JavaScript・画像は相対パス、ページ内リンクはフラグメントで指定しており、`/swinglab/` 配下でも動作します。カスタムドメインや絶対パスの設定は不要です。

Pagesの設定が利用できない場合は、リポジトリの権限・公開範囲・GitHubプランのPages対応を確認してください。公開後はスマートフォン表示、予約準備中の案内、Googleマップの表示・所在地を確認してください。

## 現時点の仕様

- 会員予約・ビジター予約は仮の導線です。ボタンに「準備中・予約不可」と表示し、クリックすると案内を開きます。実際の予約・情報送信は行いません。
- 料金は「料金プラン準備中」と表示しています。
- 利用の流れは予定として掲載しています。入退館・レンタル・駐車場など、未確定の情報は準備中としています。
- 施設ビジュアルはオリジナルSVGのイメージイラストで、実施設の写真ではありません。実際の設備・内装を示すものではありません。
- Googleマップの表示と外部地図リンクにはインターネット接続が必要です。それ以外の表示や操作は外部サービスに依存しません。
- Googleマップの埋め込みを表示するとGoogleへ接続します。公開前に、必要に応じて実際の運用に合ったプライバシーの案内を用意してください。

## 動作確認項目

1. スマートフォン幅で横スクロールがなく、下部の予約ボタンがスクロール中も固定されること。
2. モバイルメニューが開閉し、各セクションへ移動できること。
3. 会員予約・ビジター予約のそれぞれで準備中の案内が表示され、閉じるボタン・Escapeで閉じること。
4. FAQが開閉でき、料金や予約が準備中と案内されること。
5. デスクトップ幅で施設情報・地図・各セクションが表示されること。

## 確認結果

- Chromiumで画面幅320 / 375 / 390 / 640 / 768 / 900 / 1024 / 1440pxを確認。
- 横スクロール、画像表示、ページ内リンク、FAQ開閉、モバイルメニュー、会員・ビジター両方の予約案内、下部ボタンの固定表示を確認。
- デスクトップの予約案内、ダイアログ終了時のフォーカス復帰、静的ファイルのHTTP応答を確認。JavaScript実行エラーなし。
- Googleマップは検証環境の外部アクセス制限で取得できませんでした。ローカルUI検証では埋め込み先を隔離しています。実際の地図表示・ピン位置は未検証です。

`/swinglab/` 配下での静的配信もChromiumで検証しています。

正式公開前に、正式な料金・予約URL・利用手順・実施設写真とGoogleマップの所在地を確認してください。
